# Touristic Website Project

## Project Overview
This project is a multi-page touristic website created using **HTML, CSS, and vanilla JavaScript**.  
It showcases famous monuments from around the world and was developed as part of the **I2201 – Final Project**.

The goal of the project is to practice building a complete, responsive website with structured content, styling, and basic interactivity without using any frameworks or backend technologies.

---

## Website Pages
The website includes the following pages:

- **Home (index.html)**  
  Introduction to the website with short informational articles.

- **Gallery (gallery.html)**  
  A responsive grid displaying monument thumbnails that link to individual monument pages.

- **Monument Detail Pages (monument-1.html, monument-2.html, etc.)**  
  Each page contains an image, historical description, and quick facts about a monument.

- **About (about.html)**  
  Information about the project and the technologies used.

- **Feedback (feedback.html)**  
  A feedback form with client-side validation using JavaScript.

---

## Technologies Used
- HTML5 (semantic structure)
- CSS3 (layout, styling, responsiveness)
- JavaScript (DOM manipulation and form validation)

---

## JavaScript Functionality
The JavaScript file (`js/main.js`) provides the following features:

- **Active Navigation Highlight**  
  Automatically highlights the current page in the navigation bar.

- **Feedback Form Validation**  
  - Checks that the name field is not empty  
  - Validates email format  
  - Ensures the message has a minimum length  

- **Data Storage**  
  On successful submission, feedback data is saved in the browser using `localStorage`.

## How to Run the Project
1. Download or unzip the project folder.
2. Open `index.html` in any modern web browser.
3. Navigate through the website using the menu.

No additional setup is required.
